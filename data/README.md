# Data

Raw data is not committed to this repo. Download both files from the source below and place them in this folder:

- `ab_data.csv` — one row per user visit: user_id, timestamp, group, landing_page, converted
- `countries.csv` — user_id and country

Source: Udacity Data Analyst Nanodegree, "Analyze A/B Test Results" project. Copy obtained from https://github.com/igorstojanovic91/udacity-a-b-test
